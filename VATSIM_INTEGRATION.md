# APEX AIR - VATSIM INTEGRATION GUIDE

## Getting Started with VATSIM

### 1. Create VATSIM Account
- Go to https://vatsim.net
- Click "Sign Up" or "Create Account"
- Fill in required information
- Verify email address
- Create VATSIM ID

### 2. Download Flight Simulation Software

Choose one or more:
- **X-Plane 11/12** (Recommended for realism)
- **Microsoft Flight Simulator** (Modern, accessible)
- **FSX: Steam Edition** (Older, stable)

### 3. Install VATSIM Client

**Recommended VATSIM Clients:**
- **vPilot** (Most popular for pilots) - https://vpilot.rosscarlson.dev/
- **Xsquawkbox** (Integrated, good UI) - https://www.xsquawkbox.net/
- **Euroscope** (For ATC training)

### 4. Configure Your Client

**Required Information:**
- VATSIM Account ID
- VATSIM Password
- Real Name
- Callsign (AAX### format for Apex Air)
- Aircraft Type (B737, A320, etc.)

## Flight Operations

### Daily Operations Schedule

**Peak Hours (Most ATC Coverage):**
- 1600-2200 UTC (Morning/Afternoon North America)
- 0600-1200 UTC (Evening/Night Europe)
- 2200-0400 UTC (Early morning Asia-Pacific)

**Recommended Flight Times:**
- Plan flights during these hours
- Check event calendar on VATSIM website
- Avoid low-coverage periods

### Flight Plan Filing

**When to File:**
- 30 minutes before departure
- Use VATSIM flight plan system
- File through your flight client

**Required Information:**
```
Flight: AAX101
Departure: KJFK (New York)
Arrival: EGLL (London)
Aircraft Type: B777
Cruise Altitude: FL350
Alternate: EGCC (Manchester)
```

### Coordinate with ATC

**Check Before Departing:**
- Is Ground frequency active?
- Is Tower frequency active?
- Is Departure frequency active?
- Is Approach frequency active at destination?

**Find Active Frequencies:**
- Visit https://vatsim.net/status
- Check online ATC list
- Look at network map
- Use VATSIM radar

## VATSIM Ratings Explained

### Pilot Ratings
| Rating | Meaning | Privileges |
|--------|---------|-----------|
| S1 | Suspended Pilot | VFR below 10,000 ft |
| S2 | Suspended Pilot | VFR up to 10,000 ft |
| S3 | Suspended Pilot | IFR ops, higher alt |
| C1 | Commercial Pilot | Advanced IFR |
| C3 | Airline Transport | Captain operations |
| I1 | Instructor | Can train pilots |

### Rating Requirements for Apex Air
- **Minimum:** S1 rating
- **Recommended:** S3+ for international routes
- **Best:** C1+ for long-haul operations

### Improve Your Rating
- Fly frequently on VATSIM
- Follow procedures consistently
- Complete training courses
- Request check rides
- Get endorsements

## ATC Coordination

### When ATC is Online
✅ **DO:**
- Follow all instructions
- Request clearances properly
- Maintain assigned altitudes
- Report positions
- Use standard phraseology

❌ **DON'T:**
- Exceed assigned speeds
- Deviate from vectors
- Argue with decisions
- Interrupt other pilots
- Disappear without notice

## Troubleshooting Common Issues

### Can't Connect to VATSIM
- Verify internet connection
- Check VATSIM status page
- Verify callsign format
- Restart flight client
- Check firewall settings

### ATC Not Responding
- Check frequency is correct
- Verify ATC is online
- Wait for frequency to become active
- Try different airport
- Check controller availability

### Disconnected Mid-Flight
- Log back in immediately
- Inform ATC if connected
- File new flight plan
- Resume from current position
- Discuss with dispatch

### Flight Data Issues
- Verify aircraft type matches
- Check flight plan filing
- Ensure realistic performance
- Check gross weight calculation
- Verify fuel amount

## Performance Standards

### Speed Limits (Mandatory)
```
Below 10,000 ft: 250 knots or less
10,000-18,000 ft: 280 knots or less
Above 18,000 ft: Mach 0.78 or less
```

### Altitude Compliance
- Maintain ±100 feet of assigned altitude
- Don't climb/descend without clearance
- Follow published procedures
- Respect airway restrictions

### Realistic Operations
- Use realistic climb/descent rates
- Don't accelerate instantaneously
- Maintain realistic speeds
- Follow procedure patterns
- Use realistic fuel consumption
