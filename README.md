## 📝 Customization Guide

### Update Airline Information
Edit the following in `index.html`:
- Callsign and airline name (in navigation and throughout)
- Contact email: `recruitment@apexair.net`
- Discord server link
- Flight numbers and routes in schedules table
- Pilot requirements in pilot section

### Modify Colors
Edit `:root` variables in `styles.css`:
```css
:root {
    --primary-color: #1a472a;      /* Main color */
    --secondary-color: #2d5f3f;    /* Secondary color */
    --accent-color: #4a8f5f;       /* Accent color */
}
```

### Update Fleet
Modify the aircraft cards in the fleet section to match your actual aircraft:
- Change aircraft model names
- Update descriptions
- Adjust aircraft count

### Add Real Logo
Replace the SVG logo in the navbar with your actual logo:
```html
<img src="logo.png" alt="Apex Air Logo" class="logo">
```
